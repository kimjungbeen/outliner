# 로컬 outliner

Flask + SQLite + 브라우저로 만든 내 컴퓨터용 outliner예요.

## 실행
- **다른 맥에 설치 · 업데이트 (막히지 않게)**: 터미널에 한 줄 — `curl -fsSL https://raw.githubusercontent.com/kimjungbeen/outliner/main/install.sh | bash`. `~/Outliner`에 받고(다시 하면 코드만 바꾸고 `data/`는 그대로) 응용 프로그램 폴더에 `Outliner.app`을 만들어 열어요. curl로 받은 파일엔 격리 표시가 붙지 않아서 '확인되지 않은 개발자'로 막히지 않아요. 공개 저장소에는 `packaging/publish_github.sh`로 올려요(main의 outliner 폴더).
- **맥**: `Outliner.command`를 더블클릭해요. 처음 한 번 실행하면 이 맥의 응용 프로그램 폴더에 `Outliner.app`을 만들어요 (`/Applications` — 쓸 수 없는 계정이면 `~/Applications`) — 다음부터는 그걸로 열어요 (Launchpad · Spotlight에서 Outliner).
  - 다른 곳(웹 · 메신저 · 클라우드)에서 받은 폴더는 맥이 격리 표시를 붙여서 `Outliner.command`가 '확인되지 않은 개발자'로 막혀요. 클라우드 앱이 파일을 다시 받으면 표시가 또 붙어요. 처음 한 번만 터미널에서 `xattr -dr com.apple.quarantine <폴더>` 하거나 시스템 설정 › 개인정보 보호 및 보안 › '그래도 열기'로 열면, 실행할 때 폴더 전체에서 표시를 떼고 위 앱을 만들어요.
  - `Outliner.app`은 이 맥에서 만든 앱이라 격리 표시가 없고, `Outliner.command`를 bash로 실행해서 그 파일에 표시가 다시 붙어도 막히지 않아요. 터미널 창 없이 열려요 (기록: `~/Library/Logs/Outliner.log`, 준비 · 오류는 알림 · 경고 창으로). 폴더를 옮기면 `Outliner.command`를 한 번 더 실행하면 앱을 다시 만들어요. 아이콘은 앱 화면 아이콘과 같은 ⇥ (`src/mac/`).
- **설치 파일(파이썬까지 들어 있어서 따로 설치할 게 없어요)** — 만들기는 맥에서:
  - **맥 `Outliner.dmg`** (`bash packaging/mac/build_dmg.sh`): 열어서 `Outliner.app`을 Applications로 끌어다 놓아요. Apple Silicon · Intel 파이썬이 둘 다 들어 있어요. 창은 크롬이 아니라 앱 자체 창(pywebview — 맥 내장 WebKit)이라 크롬이 없어도 돼요 · 새 창은 파일 › 새 창(⌘N). 데이터는 `~/Library/Application Support/Outliner` (이 폴더 방식의 `data/`와 따로 — 옮기려면 `data/` 안의 것을 그리로 복사). 기록은 `~/Library/Logs/Outliner.log`. 애플 개발자 서명이 없어서 다른 맥에서는 처음 한 번 '그래도 열기'(시스템 설정 › 개인정보 보호 및 보안)가 필요해요.
  - **안드로이드 `Outliner.apk`** (`bash packaging/android/build_apk.sh` — JDK 17+ · 안드로이드 SDK · python3.12 필요): 설치만 하면 열려요. 앱 안의 파이썬(Chaquopy)이 서버를 `127.0.0.1:4301`에 켜고 WebView로 보여 줘요. 데이터는 앱 안(앱을 지우면 같이 지워져요 — Dropbox 맞추기나 내보내기로 옮겨요). 내려받기는 휴대폰 '다운로드' 폴더로, 바깥 링크(Dropbox 허용하기 …)는 휴대폰 브라우저로 열려요. 서명 키는 `~/.android/outliner-release.jks` — 같은 키로 만들어야 업데이트 설치가 돼요.
- 처음 실행할 때만 이 폴더 안에 `.venv`(전용 파이썬 환경)를 만들고 필요한 패키지(flask)를 내려받아요. 1~2분 걸리고 인터넷이 필요해요. 그다음부터는 바로 열려요.
- 파이썬 3.9 이상이 있어야 해요. 없으면 python.org 다운로드 페이지를 열어 줘요.
- `requirements.txt`가 바뀌면 다음 실행 때 알아서 다시 설치해요. 꼬였을 때는 `.venv` 폴더를 지우고 다시 실행하면 처음부터 새로 준비해요.
- 앱 창을 모두 닫으면 서버도 꺼지고 터미널 창도 끝나요. 앱이 켜져 있는 동안에는 터미널 창을 닫지 마세요.

손으로 실행하려면 `pip install -r requirements.txt` 후 `python src/server.py`. 주소는 `http://127.0.0.1:4300` (다른 포트: `OUTLINER_PORT=5200 python src/server.py`). 브라우저는 자동으로 열지 않아요 — 열리게 하려면 `OUTLINER_OPEN_BROWSER=1 python src/server.py`. 5000번은 맥의 AirPlay 수신 모드와 겹쳐 간헐적으로 403이 나서 쓰지 않아요.

## 대용량 설계 (노드 수십만 개)
- **지연 로딩**: `/api/view`가 지금 화면에 필요한 것(현재 항목의 자식 + 펼쳐진 항목의 자식)만 돌려줘요. 접힌 항목은 펼칠 때 불러와요.
- **부분 그리기**: 한 부모 아래 300개씩 그리고 "더 보기". 편집은 바뀐 행/부모만 다시 그려요. 화면 밖 행은 CSS `content-visibility`로 배치를 건너뛰어요.
- **즉시 반응**: 새 항목·삭제·접기는 서버 응답을 기다리지 않고 화면이 먼저 바뀌어요(id는 `/api/reserve`로 미리 받아 둠). 서버 저장은 순서 보장 큐로 처리해요.
- **검색**: 공백 = AND, `-낱말` = 제외, **`"따옴표"` = 글자 그대로**(공백 포함 · 대소문자까지 구분, 닫는 따옴표를 아직 안 써도 돼요, 제외어도 `-"…"`로 가능). 전역 검색 결과를 고르면 그 항목 안으로 줌인해요. SQLite FTS5(trigram) 색인. 3글자 이상 낱말은 색인, 그보다 짧으면 LIKE. 결과는 최대 100개.
- **이동/삽입**: 형제를 전부 다시 매기지 않고 들어갈 자리 뒤쪽만 밀어요 (`before_id` / `after_id`).

## 여러 브라우저 동기화
같은 서버에 접속한 화면이 여러 개면(브라우저 두 개, 다른 기기 등) 한쪽에서 만들거나 고치거나 지우거나 접으면 다른 쪽이 1초 안에 따라와요. 서버가 쓰기 때마다 알림(Server-Sent Events, `/api/events`)을 보내고, 자기가 한 변경이 아닌 알림이 오면 저장하지 않은 글을 먼저 저장한 뒤 현재 화면을 다시 받아요(커서·선택 유지, 한글 조합·드래그 중에는 끝난 뒤에). 같은 항목을 동시에 고치면 나중에 저장한 쪽이 이겨요.
한 브라우저 안의 창(탭)들은 실시간 연결을 **하나만** 열어 나눠 써요 (그중 한 창이 연결을 맡고 소식을 다른 창에 전해 줘요, 그 창을 닫으면 다른 창이 이어받아요). 브라우저는 한 주소에 동시에 6개까지만 연결해서, 창마다 연결을 열면 창을 6개 넘게 띄웠을 때 새로고침이 계속 로딩에 멈췄어요. 테스트: `python3 tests/manytabs_test.py <앱 포트>`.

## 앱 바탕과 플러그인
앱이 스스로 하는 일은 **아웃라이너**(쓰기 · 옮기기 · 접기 · 줌, 마크다운 모양으로 보여 주기), **파일 보기**(PDF · 이미지 · 오디오 · 영상), 그리고 **⌘/ 명령 목록**뿐이에요. 나머지(검색 · 서식 넣기(굵게 · 형광펜 · 제목) · 내보내기 …)는 모두 `plugins/`의 명령이에요.
플러그인이 앱에 나타나는 곳은 네 군데예요 (그리고 ⌘/ 명령 목록) (명령을 등록할 때 정해요, 사용자는 ⌘/에서 바꿔요):
1. **단축키** — `keys: 'Alt+Q'`
2. **선택 막대**(항목을 고르면 아래에 뜨는 막대) — `selection: '단추 글'`, `selectionMin`
3. **글자 메뉴**(글자를 고르면 위에 뜨는 작은 메뉴) — `text: { label, title, style, group, order, active(ctx), hidden(ctx), render(ctx), marks }`
4. **태그 누르기**(글 속 `#태그` · `@사람`을 누르면) — `tag: true`. 켠 명령이 하나면 바로, 여럿이면 명령 이름 메뉴로 골라요. 누른 태그가 run의 첫 인자 (기본: `find`)

플러그인은 **사용자가 부를 때만** 실행돼요 — 단축키 · ⌘/ 명령 목록 · 선택 막대 · 글자 메뉴 · 태그 누르기. 앱이 그리거나 고칠 때 저절로 끼어드는 길(글 그리기 · 소식 받기 · 행 꾸미기)은 없어요. 글 모양(마크다운)은 앱 기본이에요.

플러그인과 앱은 **api로만** 만나요. 플러그인은 앱 파일(`/app.js` · `/dialog.js` · `/lib.js` …)을 가져오지 않고, 서버 주소(`/api/…`)를 직접 부르지 않고(바깥 서비스 — Dropbox API 같은 `https://…` — 는 플러그인이 직접 불러도 돼요), 앱 화면 구조(`#tree` · `.row` …)를 만지지 않아요 — `tests/boundary_test.py`가 글로 훑어 지켜요. 앱 파일 쪽도 플러그인 이름을 몰라요 (예전 명령 이름 옮기기는 서버가 처음 켤 때 한 번 해요 — `server.py` `_migrate_prefs`).

**파일 보기의 경계**: 파일을 **보고 다루는 능력**(PDF · 이미지 · 오디오 · 영상 보기와 편집, 북마크, 구간 반복, 첨부 올리기 · 내려받기, 노트 PDF 만들기, 형식 바꾸기 · 인쇄)은 앱이 가져요. 그 능력을 **부르는 단추와 고르는 창**(첨부 관리 `file` · 북마크 찾기 `bookmarks` · 여러 PDF에서 찾기 `pdfsearch` · 전체 재생 `play` · 노트 `note` · 녹음 `record` · 가져오기 `import` · 내보내기 `export`)은 플러그인이에요 — 앱 능력은 `api.files` · `api.export`로 열려 있어요. 끌어놓기 · 붙여넣기로 파일을 넣는 건 아웃라이너 편집이라 앱이 해요.

## 명령 목록 (⌘/ · Ctrl+/)
**⌘/**(Windows · Linux **Ctrl+/**)를 누르면 모든 명령이 ★ 다음 알파벳 순으로 떠요. 찾기 칸으로 거르고(↑↓ · Enter), 줄을 누르면 실행해요. 줄마다 내가 정해요:
**☆/★** 고정(맨 위 · 모바일 막대) · **막대** 선택 막대에 띄우기 · **글자** 글자 메뉴에 띄우기 · **태그** 태그를 누르면 부르기 · **단축키** 누르면 그 자리에서 바꾸기 · 지우기 · 기본값. 맨 아래에는 앱 자체의 편집 · 이동 키(`cmdlist.js`의 `CORE_KEYS`)가 있어요.
기본 단축키는 아래 몇 가지뿐이고, 나머지 기능은 모두 **명령**이에요.

이 앱에만 있는 것만 적었어요 (되돌리기·복사·선택·Tab 들여쓰기처럼 다른 앱과 같은 키는 생략).

### 명령 기본 단축키
명령 창에 뜨는 명령은 모두 `plugins/` 폴더의 파일이에요 (파일 이름 = 명령 이름). 기본 단축키도 그 파일이 정해요.
명령 이름은 하는 일을 나타내는 영어 한 단어예요 (예전 줄임말 `ca` · `rx` · `fs` · `mt` · `tc` · `rv` · `dt` · `sc` · `lf` … 에 정해 둔 단축키 · 즐겨찾기는 새 이름으로 옮겨져요).
⌘/ 명령 목록에서 명령마다 오른쪽에 단축키가 보여요. 누르면 바꾸기 · 지우기 · 기본값으로 되돌리기를 할 수 있어요.
바꾼 단축키와 ★ 고정은 DB에 저장돼요 → 같은 서버에 붙은 브라우저·기기는 모두 같은 단축키를 써요. 명령 목록은 ★ 즐겨찾기 다음 **알파벳 순**이에요 (사용 횟수는 세지 않아요).
기본 단축키는 모두 **⌃+알파벳 하나**(Windows · Linux는 Alt+알파벳 — Windows의 Ctrl은 복사 · 붙여넣기 · 브라우저와 겹쳐서)예요. Mac 글 칸에서 원래 쓰는 ⌃ 키(⌃A 줄 앞 · ⌃E 줄 끝 · ⌃B · ⌃F · ⌃N · ⌃P 이동 · ⌃H · ⌃D · ⌃K 지우기 · ⌃O · ⌃T · ⌃V · ⌃Y · ⌃L · ⌃W)와 Windows 브라우저가 가로채는 Alt+D · E · F는 쓰지 않아서 11자뿐이에요 — 나머지 명령(— 표시)은 기본 단축키 없이 ⌘/에서 지정해요. 앱 자체 키(⌘/ · ⌘. · ⌘, …)만 ⌘예요.

`tree` · `replace` · `generate` · `sort` 창은 왼쪽에 입력 · 오른쪽에 미리 보기를 두어 스크롤 없이 한 화면에 보여요 (좁은 화면에서는 위아래로). 식 · 패턴 설명은 **?** 를 눌러야 펼쳐지고, 취소 · 실행 버튼은 창 아래에 붙어 있어 창이 작아 안쪽이 스크롤돼도 늘 보여요.

## 플러그인 API 참고
**불러오기**: 앱이 켜질 때 서버에 `plugins/`의 `.js` 목록을 물어(`/api/plugins`, `_`로 시작하는 파일은 빼요) 이름 순서대로 하나씩 불러요. 그 파일의 `default` 함수를 `api`와 함께 불러요 — `api`는 `src/static/api.js`가 만들어 주는 하나뿐인 다리예요 (얼려 둬서 고칠 수 없어요). 처음 화면을 그리기 전에 모두 끝나요. 한 파일이 실패해도 다른 명령은 그대로 불러와요 (콘솔에 오류).
**명령 만들기**: `plugins/새이름.js` 한 파일에
```js
import { command } from './_kit.js';
export default (api) => command(api, { name: '새이름', label: '하는 일 (덧붙임)', keys: 'Alt+Q', preload: false, make: (api, ui, t) => ({ 새이름: () => ui.toast('안녕') }) });
```
`keys`는 기본 단축키(⌃+알파벳 하나 — Mac 글 칸의 ⌃ 키와 겹치지 않게), `selection: '단추 글'`은 항목을 고를 때 선택 막대의 단추(`selectionMin`개 이상, 기본 1), `text: { label: 'B' }`는 글자 메뉴의 단추(`render(ctx)`로 직접 그리기도 — 형광펜 색들처럼). 띄울지는 사용자가 ⌘/의 **막대** · **글자**로 바꿔요. 어떤 길로 부르든(단축키 · ⌘/ · 선택 막대 · 글자 메뉴) **그때 고른 글자가 run의 첫 인자**로 와요 (태그를 눌러 부르면 그 태그) (`make`의 함수도 `(글자) => …`로 받아요, `api.text.picked()`로도) — 글을 입력받는 명령(`jump` · `find` · `replace` · `delete` · `tree` 찾아 펼치기 · `verse` · `move` · `generate` · `bookmarks` · `pdfsearch`)은 그 글자를 입력 칸에 미리 넣어요. 고른 글자가 없으면 인자도 없어요. `api.ui.prompt(안내, 목록, { value })`로 입력 칸에 미리 넣을 수 있어요. 받아 오는 목록(서버 검색 등)은 `{ source: async (글) => [{ v, label, sub }] }` — '치고 고르는 창'은 모두 이 모양 하나예요 (`move`도). `preload: true`(기본)면 실행 전에 지금 화면 아래 항목을 모두 불러와요. `make(api, ui, t)`는 처음 실행할 때 한 번 (`ui` = `api.ui`, `t` = `_tools.js` 트리 도구 — `await t.picked()`는 '고른 항목, 없으면 지금 화면 아래 전부').

## 검색 창 (`jump` · `find` 플러그인)
⌘/에서 실행하거나 단축키를 지정해 열고 Esc로 닫아요. **전역 검색은 `jump`**(고르면 그 항목 안으로, ⌘+클릭 · ⌘Enter는 그 항목이 있는 화면으로), **하위 검색은 `find`**(지금 화면 아래에서만, 고르면 이동 없이 그 항목까지 펼쳐요) — 따로 된 명령이라 창 안에서 바꾸지 않아요. 같은 본체(`plugins/_search.js`)를 범위만 다르게 써요. 명령은 검색 창이 아니라 ⌘/ 명령 목록에 있어요. 쓰는 API: `api.nodes.search` · `api.ui.loadHistory` · `api.ui.remember` · `api.view.goTo` · `api.view.reveal` · `api.view.copyUrl` · `api.md`. 덮개 창은 `data-overlay`를 달면 떠 있는 동안 앱이 커서 · 키를 빼앗지 않아요.
**태그는 그대로만 찾아요**: `#태`를 찾으면 `#태`만 나오고 `#태그`는 안 나와요 (`@사람`도 같아요, `-#태그`로 빼기). 태그가 아닌 낱말은 예전처럼 일부만 맞아도 찾아요.
**입력 기록 = 즐겨찾기**: 따로 '항목 즐겨찾기'는 없어요 — 입력을 받는 명령(`jump` · `find` · `replace` · `delete` · `verse` · `tree` …)은 명령마다 **최근에 넣은 값**과 **★ 고정**이 입력창 아래에 나와요. ★가 맨 위(넣은 순), 그다음 최근 순 (언제 썼는지 함께). ☆를 누르거나 ⇧Enter로 ★ (아무것도 안 골랐으면 지금 입력한 글자를). 입력칸이 빈 채로 Enter를 누르면 맨 위 기록으로 바로 다시 실행해요. 기록을 고쳐서 쓰려면 줄 오른쪽의 **✎** 또는 **Tab**(고른 줄): 실행하지 않고 입력칸에 글자만 넣어 줘요. 고친 뒤 Enter로 실행해요. `fr`은 '찾기 → 바꾸기' 짝으로 기록되고 누르면 두 칸이 채워져요. 플러그인에서는 `api.ui.prompt(msg, presets, { history: '이름' })`, 대화상자에는 `api.ui.historyPanel('이름', { onPick })` + `api.ui.remember('이름', 값)`. **기록 지우기**: 기록 줄마다 ✕ (또는 고른 줄에서 ⇧Delete · ⌘⌫) — 플러그인에서는 `api.ui.forget('이름', 값)` · `api.ui.clearHistory('이름', { favs })`.
정규식 검색은 서버가 행을 훑어요(34만 개 전체 ~0.5초, 하위 범위면 그만큼 작아져요).

## 첨부 (이미지 · 영상 · 오디오 · PDF)
- 넣는 법: 파일을 항목 위로 **끌어다 놓기** / 캡처 · 복사한 이미지 **붙여넣기(Ctrl/⌘+V)** / `import` 명령(⌃I, 파일 넣기 — 백업 · 글 파일도 같은 곳으로). 빈 항목이면 그 자리에, 아니면 그 항목 아래에 새 항목으로 들어가요.
- **웹페이지 이미지 끌어다 놓기**: 다른 브라우저 창의 웹페이지에서 이미지를 끌어다 놓아도 첨부돼요. 브라우저가 파일을 주면 그대로 올리고, 주소만 주면 서버가 그 주소에서 내려받아요(`/api/upload-url`, png jpg gif webp avif bmp, 100MB까지). 이미지가 아닌 링크는 글 입력칸에 놓으면 평소처럼 글로 들어가요. 로그인해야 보이는 이미지는 주소로 못 받을 수 있어요. 그럴 땐 이미지를 복사해서 붙여넣으세요.
- 항목 글에는 `![이름](/files/해시.확장자)` 가 적히고(옅게 표시), 그 아래에 이미지·영상 플레이어·오디오 플레이어·PDF 보기가 나와요. 글을 지우면 미리보기도 사라져요.
- **이미지 보기**: 이미지를 누르면 새 탭 대신 이 화면 안에서 크게 열려요(⌘ · Ctrl+클릭은 새 탭). 화면에 있는 이미지들을 ← → (또는 ‹ › 단추)로 앞뒤로 넘기고, 휠 · 두 손가락 벌리기 · 더블클릭 · + − 로 확대, 끌어서 이동, 0으로 화면에 맞추기, **내려받기**(↓ — 글에 적힌 이름으로), Esc로 닫기. 창 크기가 바뀌거나 폰을 돌려도 보던 영역이 그대로 보여요.
  **북마크**(책갈피 단추)는 PDF 북마크와 같아요: '영역 지정해 북마크 만들기'를 누르고 이미지 위에서 끌어 사각형을 그리면 이름을 받아 저장하고 링크(`/?img=이미지&r=x,y,너비,높이#항목`)를 복사해요. 목록에서 누르면 그 영역으로 확대 · 잠깐 강조, 이름 고치기 · 링크 복사 · 지우기. 링크를 열거나 항목 글에 넣고 누르면 같은 이미지의 그 영역이 열려요. 이미지마다 DB(plugin_data `core` `img_marks`)에 저장돼 전체 백업 · 아래에 추가에 함께 들어가요. 북마크가 둘 이상이면 칸 위에 **찾기 칸**이 나와 이름으로 걸러요(Enter = 첫 결과로, PDF 북마크는 `3쪽`처럼 쪽으로도). 모든 파일의 북마크는 `bookmarks` 명령(**북마크 찾기**)으로 한꺼번에 찾아 열어요 — PDF는 그 항목 안으로, 이미지는 그 영역을 크게.
  **북마크를 파일과 함께 넘기기**: PDF · 이미지의 **내려받기**(↓)는 북마크가 있으면 파일 안에 담아서 받아요 — PDF는 표준 **책갈피(목차)**로도 써서 미리보기 · Acrobat 같은 다른 PDF 앱에서도 책갈피 목록으로 보이고 누르면 그 자리로 가요(원래 목차가 있으면 맨 뒤에 '북마크' 묶음으로), 정확한 영역은 문서 정보(`/OutlinerMarks`)에 따로 담아요. 이미지는 PNG(tEXt) · JPEG(주석 칸)에 outliner 전용으로 담아요(다른 앱에서는 안 보이고 그림은 그대로). 첨부 관리(`af`)에서 골라 **다운로드**해도 마찬가지예요 — 북마크 · 마크업이 있는 파일은 담은 판으로 바꿔 ZIP에 넣어요. 그 파일을 다시 **첨부**하면(끌어놓기 · 붙여넣기 · `import`) 담긴 북마크가 새 첨부의 북마크로 되살아나요. **JSON 내보내기**에도 항목에 든 파일의 북마크가 `pdf_marks` · `img_marks`로 함께 들어가고, JSON 가져오기에서 되살려요. (JSON에는 파일 자체는 들어가지 않아요 — 파일까지 옮기려면 전체 백업 ZIP) (⌘C는 지금 보는 화면 그대로의 링크를 복사해요.)
  **마크업**(연필 단추): 펜 · 형광펜(색 · 굵기, Shift나 끝에서 잠깐 멈추면 직선) · 지우개 · 글자(누른 자리에 넣고, 끌어서 옮기고, 누르면 고치거나 지우기) · 되돌리기(⌘Z) — PDF 편집과 같은 도구 · 색이에요. 좁은 화면에서 마크업 중에는 머리말 · 도구 막대가 두 줄로 줄어 그림 칸이 넓어지고, 그리다가도 두 손가락이면 확대 · 이동이에요. **저장**하면 그린 것을 입힌 새 이미지(JPEG는 JPEG, 나머지는 PNG)가 올라가고 이 항목의 첨부가 그 파일로 바뀌어요. 북마크도 새 파일로 따라가요. **저장한 뒤에도 다시 고칠 수 있어요**: 원본과 그린 것(선 · 글자 하나하나)을 따로 기억해서(DB `core` `img_ink`), 다시 마크업을 켜면 원본 위에 그린 것이 되살아나 지우고 · 옮기고 · 더할 수 있어요. 다 지우고 저장하면 원본으로 돌아가요. 원본 파일은 첨부 관리에서 '마크업 원본'으로 표시되고 '안 쓰는 파일 정리'에서 빠져요. 내려받기 · `af`로 받으면 원본과 그린 것이 그 이미지 파일 안(PNG 비공개 덩어리 · JPEG APP15 칸)에 담겨서, 백업한 파일을 다시 첨부해도 계속 고칠 수 있어요.
- **PDF**는 처음부터 펼쳐진 채로 이 화면 안에서 보여요 (PDF.js, `src/static/vendor/pdfjs/`, Apache-2.0). ‹ › 로 페이지 이동, 페이지 번호를 눌러 숫자를 넣고 Enter 하면 그 페이지로 (Esc는 취소), PDF 안의 링크도 눌러져요 (웹 주소는 새 탭, 목차·각주 같은 문서 안 링크는 그 페이지로), **맞춤** 단추 하나로 가로 ↔ 세로 맞춤을 바꿔요(아이콘이 지금 맞춤 · 세로 맞춤에서 너비가 넉넉하면 두 쪽씩 나란히), **확대**: 두 손가락 벌리기(폰 · 태블릿) · ⌘/Ctrl+휠(트랙패드 오므리기) — 50%~600%, 확대하면 배율 단추가 나오고 누르면 맞춤 크기로, **내려받기**(↓ — 글에 적힌 이름으로, 예: `노트 2026-10-26.pdf`), '접기'로 닫기.
- **PDF 편집**(연필 버튼): 펜 · 형광펜(끌어서 그리기 — 고르면 옆에 **색**(펜 5 · 형광펜 4)과 **굵기**(3단계)가 나와요, 마지막에 고른 것을 기억; 선은 부드러운 곡선으로 다듬고 점을 줄여 저장; **Shift**를 누르고 그리거나 긋다가 **잠깐 멈추면 직선**) · **지우개**(문지르면 지나간 자리의 펜 · 형광펜 자국이 하나씩 지워져요, 되돌리기로 하나씩 살려요) · 글자(누른 자리에 글 넣기, 한글 그대로) · 메모(아이콘, 마우스를 올리면 내용) · 지금 페이지 돌리기 · 앞으로/뒤로 · 삭제 · **빈 쪽 추가**(점선 종이 + 아이콘, 맨 뒤에, 지금 쪽과 같은 크기 — `note`로 만든 노트면 같은 종이로) · **PDF 불러와 합치기**(겹친 종이 ↓ 아이콘) · 되돌리기. 편집을 켜면 **화면 가득**으로 바뀌고(끝나면 원래대로), 좁은 화면에서는 이름 · 북마크 · 내려받기를 숨기고 도구 막대를 한 줄(옆으로 밀기, 취소 · 저장은 오른쪽에 붙어 있어요)로 줄여 페이지 칸을 최대한 넓게 써요. 그리는 중에 두 번째 손가락이 닿으면 긋던 선은 버리고 확대로 바뀌어요. 고친 것은 화면에만 바로 반영되고(빨라요) **저장할 때 한 번에** PDF에 써요 — 고친 PDF가 새 파일로 올라가고 이 항목의 첨부가 그 파일로 바뀌어요(원래 파일은 첨부 관리에서 지울 수 있어요). 편집 중에 펜 자국 · 형광펜 · 글자 · 메모를 누르면 지우거나 고치고, **글자 · 메모는 끌어서 옮겨요**(도구가 없거나 글자 · 메모 도구가 켜져 있을 때). 메모 도구를 고르면 **메모 아이콘 색**(5가지)을 고를 수 있어요(저장한 PDF에도 그 색으로). pdf-lib(`src/static/vendor/pdf-lib/`, MIT)을 써요.
- **PDF 북마크**(리본 버튼): '영역 지정해 북마크 만들기'를 누르고 페이지 위에서 끌어 사각형을 그리면 이름을 받아 북마크가 되고 **링크가 복사**돼요(`/?pdf=파일&p=쪽&r=영역&n=PDF가 든 항목#보던 화면`). 그 링크를 열거나 항목 글에 넣고 ⌘ · Ctrl+클릭하면 그 PDF를 펼쳐 그 페이지의 그 영역으로 스크롤하고 잠깐 강조해요(지금 화면에 PDF가 없으면 PDF가 든 항목 안으로 가요). 북마크 칸에는 북마크 목록(누르면 그 영역으로 · ✎ 이름 고치기 · 🔗 링크 복사 · ✕ 지우기)이 있고, 칸을 연 동안은 페이지 위에 영역이 보여요. DB(plugin_data `core/pdf_marks`)에 저장돼 다른 기기에서도 보여요. PDF 파일 자체는 바꾸지 않아요(편집 중에는 만들 수 없어요). 편집해서 저장하면 북마크도 고친 파일로 따라가요(페이지를 지우 · 옮기 · 돌리지 않았을 때 — 쪽 · 영역이 그대로일 때만).
- **화면 가득 보기**: PDF 막대의 ⛶ 버튼(새 탭 대신) — 뷰어가 창 전체로 늘어나요. Esc로 돌아와요.
- **마지막 위치 기억**: PDF는 마지막으로 보던 페이지, 영상·오디오는 마지막 재생 위치에서 다시 열려요 (끝까지 재생했으면 처음부터). DB에 저장되므로 같은 서버에 붙은 다른 브라우저·기기에서도 이어서 봐요. 항목이 다시 그려져도 재생·보던 페이지가 끊기지 않아요.
- **플레이어 조작부**: 항목 안의 오디오·영상과 아래 재생 막대가 같은 조작부를 써요 — −5초 · 재생 · +15초, 시간 글자를 눌러 `1:23` · `95` · `1분 30초`처럼 넣어 이동, **A-B**(누를 때마다 시작 → 끝 → 끄기: 구간 반복 — 켜지면 A · B 시간 칸에 직접 넣을 수도 있어요, B를 비우면 A부터 끝까지 — 정한 A–B 구간은 곡마다 **저장한 구간** 칩으로 남아 다시 누르면 그 구간 반복, ×로 지우기; 기록은 DB에 저장돼 다른 기기에서도 보여요), **반복**(항목 안: 끔 → 한 곡 / 막대: 끔 → 전체 → 한 곡). 영상은 화면을 눌러 재생 · 멈춤, 전체 화면 단추도 있어요.
- **오디오 · 영상 북마크**(책갈피 단추): 누르면 북마크 칸이 열려요. **지금 위치에 북마크**를 누르면 이름(기본은 시간)을 받아 저장하고 링크를 복사해요. 목록은 시간 순(PDF · 이미지와 같은 목록 — 누르면 그 시간부터 재생 · 고치기 · 링크 복사 · 지우기, 둘 이상이면 찾기 칸). **고치기**(연필)는 한 창에서 이름과 **시간**을 함께 고쳐요: `1:23` · `95` · `1분 30초`처럼 넣거나 **지금 위치로** 단추(지금 재생 위치), Enter로 저장 — 틀린 시간 · 곡보다 긴 시간은 알려 주고 창은 그대로, 시간 칸을 안 고치면 원래 시간(소수점까지) 그대로, 위치 막대에는 북마크 자리에 파란 눈금이 보여요(마우스를 올리면 이름). 링크(`…/?media=파일&t=초#화면`)를 열면 그 화면에서 그 시간부터 재생하고, 그 화면에 플레이어가 없으면 아래 재생 막대에서 재생해요. 재생 막대에도 같은 북마크 단추가 있어요. DB(`plugin_data` 'core' `media_marks`)에 저장 — `bookmarks` 찾기 · JSON 내보내기/가져오기 · 백업 아래에 추가 · Dropbox 맞추기에도 함께 들어가요 (파일 자체에는 담지 않아요).
- **재생 막대** (화면 아래): `play` · `play-shuffle`로 하위 항목의 오디오·영상을 화면 순서대로(또는 섞어서) 이어 재생해요. 위 조작부에 이전 · 다음 · **전체 섞기**가 더해지고, 제목을 누르면 그 항목으로 가요. **재생 목록** 단추를 누르면 지금 순서(섞었으면 섞인 순서)대로 목록이 펼쳐지고, 누르면 그 곡으로 넘어가요. 새로고침하거나 다시 열어도 재생 목록 · 지금 곡 · 위치 · 섞기 · 반복이 그대로 돌아와요 (브라우저가 저절로 소리 내는 것을 막아서 멈춘 채로 — ▶로 이어서). 제목 줄을 끌어 옮기면 놓은 곳에서 가까운 화면 모서리(네 귀퉁이)로 붙어요 (다음에도 그 모서리에). **최소화** 단추(⌄)를 누르면 제목 · 재생 · 펼치기 · 닫기만 남은 작은 막대가 돼요 (다음에도 그 모양으로).
- **같은 계층 자동 재생 목록**: 항목 안에서 오디오·영상을 재생하면 같은 계층(형제 항목)과 그 하위 항목들의 오디오·영상이 화면 순서대로 자동으로 재생 목록이 돼요 (둘 이상일 때). 그 곡은 항목 안에서 그대로 재생하고 막대에는 제목 · 재생 · 목록만 보여요. 끝나면 다음 곡을 — 화면에 있으면 그 항목 안에서, 없으면 막대에서 — 이어서 재생해요.
- **노드 순서 따라가기**: 재생 목록은 그 목록을 만든 항목 아래의 순서를 늘 따라가요 — 항목을 옮기거나 곡을 넣고 지우면(다른 기기에서 바꿔도) 목록이 저절로 다시 맞춰지고, 지금 곡과 위치는 그대로 이어져요. 순서를 바꾸고 싶으면 항목을 옮기면 돼요. 섞기를 켜 둔 동안에는 섞인 순서를 두고 새 곡만 끝에 더하고 지운 곡만 빼요.
- **항목 안 ↔ 막대 오가기**: 같은 곡을 위치 · 구간 반복 · 재생 목록 그대로 넘겨요. 막대에서 재생 중인 곡을 항목 안에서 ▶ 누르거나 막대의 '항목 안에서 재생' 단추(화면에 그 항목이 있을 때)를 누르면 항목 안으로, 항목 안에서 재생 중일 때 막대의 '막대에서 재생' 단추를 누르면 막대로 옮겨요. 막대가 재생하는 동안 항목 안의 같은 곡도 같은 위치를 가리켜요.
- **접어도 이어서**: 항목 안에서 재생하던 오디오·영상은 그 항목을 접거나 다른 화면으로 가도 재생 막대가 그 자리부터, 구간 반복 · 반복 설정도 그대로 이어서 재생해요.
- 파일은 `data/앱이름-files/` 폴더에 내용 해시 이름으로 저장돼요(같은 파일은 한 번만). 지원: png jpg gif webp avif bmp · mp4 webm mov m4v ogv · mp3 wav m4a aac ogg oga opus flac weba · pdf, 한 번에 1GB까지.
- **백업은 `export` → 전체 백업** 을 쓰세요: DB와 첨부 파일을 ZIP 하나로 받아요. ('DB만'은 DB 파일만. JSON/Markdown 내보내기에는 첨부가 글자 표시로만 들어가요.)

`export`(⌃X) → PDF…. 창 왼쪽에는 자주 바꾸는 것만 있어요: 문서 제목 · 용지(A4/A3/A5/Letter/Legal) · 방향 · 글자 크기 · **단계를 제목으로**(1단계 → H1, 2단계 → H2 … 최대 6단계) · PDF를 항목으로 넣기. 여백 · 글꼴 · 줄 간격 · 항목 사이 · 들여쓰기 · 글머리(•/–/번호/없음) · 쪽 번호 · 이미지 · 빈 항목 빼기 · 마크다운 서식은 **세부 설정**에 접혀 있어요. 오른쪽 **미리 보기**는 고칠 때마다 바로 바뀌고, 실제 쪽 나눔대로 종이처럼 보여주며 몇 쪽인지도 알려줘요(앞 30쪽까지). 'PDF 만들기'를 누르면 인쇄 창이 열려요 — 대상을 **PDF로 저장**으로 고르면 돼요. 범위는 선택한 항목, 없으면 현재 화면(접힌 항목 포함)이에요. 설정은 기억해요. 쪽 번호는 최신 Chrome/Edge에서 나와요.
**앱에 노드로 추가**를 켜면 인쇄 창 없이 서버가 Chrome/Edge(headless)로 PDF를 만들어 첨부로 저장하고, 그 PDF 항목을 현재 화면 맨 아래(항목을 골랐으면 고른 항목 아래)에 넣어요.

## 전용 창으로 실행 (화면 크게)
`Outliner.command` 또는 `python src/launcher.py` — 주소창·탭 없는 창으로 열려요. Chrome/Edge 앱 모드(`--app`)를 쓰고, 둘 다 없으면 기본 브라우저로 열어요. `--fullscreen` 으로 전체 화면.

- 서버는 **마지막 창이 닫히면** 함께 꺼져요 (창이 하나라도 남아 있으면 계속 켜져 있어요).
- 보안: 다른 웹사이트가 이 앱으로 몰래 보내는 요청(쓰기·가져오기)과 127.0.0.1·localhost 가 아닌 이름으로 들어온 접속은 거절해요.
- 테스트: `python3 tests/windows_test.py` (스스로 서버를 켜고 꺼요)


## 파일: import · export · file
파일을 다루는 명령은 셋이에요 — **들여오기는 `import`, 내보내기는 `export`(⌃X), 첨부 파일 관리는 `file`** (기본 단축키가 없는 것은 ⌘/에서). `export`나 `file`로 받은 파일은 모두 `import`로 다시 넣을 수 있어요.

| 파일 | `import`(고르기 · 끌어놓기 · 붙여넣기) | `export` · `file`로 만들기 |
|---|---|---|
| 이미지 · 영상 · 오디오 · PDF | 첨부로 (커서 · 놓은 항목 아래). 파일 안에 담긴 북마크 · 마크업도 되살려요 | `file`: 하나씩 · 골라서 · 첨부 전체 ZIP (북마크 · 마크업은 파일 안에) |
| 첨부 파일 ZIP | 풀어서 안의 이미지 · 영상 · 오디오 · PDF를 첨부로 (다른 파일은 건너뛰어요) | `file`: 여럿 고른 내려받기 · 첨부 전체 ZIP |
| JSON · HTML · Markdown · 텍스트 | 항목으로 (지금 화면 맨 아래). JSON은 접힘 · 북마크까지 | `export`: Markdown · 텍스트 · JSON (선택한 항목, 없으면 지금 화면) |
| PDF 문서 | — | `export` → PDF… (미리 보기 · 용지 · 글자 크기, 항목으로 넣기도) |
| 전체 백업 ZIP (`outliner.db` + `files/`) | 아래에 추가 · 대체하기 (첨부 파일도 함께) | `export` → 전체 백업 (범위와 상관없이 전부) |
| DB 파일 `.db` · `.sqlite` | 아래에 추가 · 대체하기 | `export` → DB만 (항목 · 북마크, 첨부 파일 빼고) |

- **백업 DB는 작게**: 지운 항목이 남긴 빈 공간과 검색 색인은 빼고 내보내요 (색인은 항목에서 다시 만들 수 있어요 — 가져오면 넣으면서, 그 파일을 그대로 앱 DB로 쓰면 켤 때 저절로). 항목 140만 개 DB가 1.6GB → 약 0.4GB.
- **크기 한도**: 첨부 파일은 하나에 1GB까지, 백업(.zip · .db)은 한도가 없어요. 너무 크면 '파일이 너무 커요'라고 알려 줘요.
- 예전 명령 `backup-all` · `export-pdf`는 `export`로, `af`는 `file`로 합쳤어요 (그 명령에 정한 단축키 · 즐겨찾기는 새 이름으로 옮겨요).
- `file` 창: 파일 목록(썸네일 · 크기 · 날짜 · **어느 항목에서 쓰는지**), 정렬, 골라서 내려받기 · 항목으로 넣기 · 삭제, "쓰는 곳 →"을 누르면 그 항목으로 가서 강조해요. 아래 단추: **안 쓰는 파일 정리**(어느 항목 글에도 없는 파일을 한 번에) · **첨부 전체 ZIP** · **폴더 열기**(파일 탐색기 · Finder).
- 백업을 넣으면 **아래에 추가** 또는 **대체하기**(바꾸기 전 `data/앱이름-before-import-날짜.db` 로 자동 백업)를 골라요.
  ZIP이면 첨부 파일도 함께 들어와요 (내용 해시 이름이라 이미 있는 파일은 건너뛰어요). 미리보기 단계에서는 첨부를 넣지 않아요.
- 통째로 바꾸면 열려 있는 모든 화면이 스스로 새로고침해요 (미리 받아 둔 새 항목 번호가 새 DB의 항목과 겹쳐 덮어쓰지 않게).

## 모바일 (안드로이드 등 터치 화면)
터치 화면에서는 아래쪽에 **보조 키**(Termux의 extra keys처럼 한 줄)가 자동으로 나타나요 (소프트 키보드 위에 붙어요). 마우스 화면에서는 보이지 않고, 주소 뒤에 `?mobile`을 붙이면 강제로 보여요.
- 기본 키: `tab shift ctrl opt cmd ← ↑ ↓ →` (Mac 키보드 왼쪽 아래 순서).
- ↑ ↓ ← →는 커서를 옮기고, 항목 끝에서 한 번 더 누르면 이웃 항목으로 넘어가요(키보드와 같아요). 길게 누르면 반복.
- **cmd · ctrl · opt · shift**: 이름 그대로의 키(⌘ · ⌃ · ⌥(Alt) · ⇧)예요. 누르면 켜지고 **키보드가 올라와요**. 다음 키 하나에 붙고(그 뒤 꺼짐), 두 번 빠르게 누르면 고정(파란 테두리), 한 번 더 누르면 해제.
  켠 채로 키보드로 글자를 치거나 보조 키를 누르면 데스크톱 단축키처럼 동작해요 — iPhone·iPad는 Mac처럼(cmd + k = 검색 창, ctrl + h = 홈, cmd shift + ↓ = 아래로 옮기기), 안드로이드는 Windows처럼(ctrl + k, opt + h, ctrl shift + ↓). shift + tab = 내어쓰기.
  켜져 있는 동안은 커서가 화면에 보이지 않는 '비밀번호' 입력칸으로 가요. 비밀번호 칸에서는 휴대폰 키보드가 단어 추천·한글 조합을 끄고
  친 글자를 그대로 보내서, 한글 자판 상태여도 영문 자판으로 바뀌어 단축키를 받을 수 있어요. 단축키를 보낼 때·모두 끌 때 커서는 원래 항목으로 돌아가요.
- **배치 바꾸기**: 명령 `mobile-keys` — Termux의 `extra-keys`와 같은 형식이에요. 예: `[["ESC","/","-","HOME","UP","END","PGUP"],["TAB","CMD","CTRL","OPT","LEFT","DOWN","RIGHT"]]`.
  키 이름(ESC TAB CMD CTRL OPT SHIFT UP DOWN LEFT RIGHT HOME END PGUP PGDN DEL) 또는 글자 하나, `{"key": "-", "popup": "|"}`처럼 쓰면 키를 **위로 밀었을 때** 두 번째 키. DB에 저장돼 같은 서버의 모든 기기가 같은 배치를 써요.
- 키를 눌러도 입력 칸의 커서가 유지돼요.
테스트: `python3 tests/mobile_test.py <앱 포트>`

## 스크롤은 사용자가 움직일 때만
- 다른 창·기기의 변경을 받아 다시 그릴 때, 접기·펼치기·옮기기로 다시 그릴 때: 커서 줄이 화면에 있으면 그 줄을, 아니면 맨 위에 보이던 줄을 기준으로 같은 자리에 맞춰요.
- 들여쓰기·내어쓰기·옮기기 뒤에도 커서 줄은 화면의 같은 높이에 그대로 있어요 (모바일에서 키보드가 다시 올라오며 밀리는 것도 잠깐 동안 다시 맞춰요).
- 다시 그리느라 잠깐 잃은 커서를 돌려놓을 때는 화면을 움직이지 않아요 (커서가 화면 밖에 있어도 그쪽으로 튀지 않아요). 새 자리로 커서가 옮겨갈 때(Enter, 화살표, 옮기기)만 따라가요.
- 다른 항목으로 들어가거나 나오면 맨 위부터 보여요.
- 끌어서 다른 항목 **안에** 넣을 때는 그 항목을 펼치지 않아요 (접혀 있으면 그대로, 하위가 없던 항목은 접힌 채로).
- 테스트: `python3 tests/ux_test.py <앱 포트>` (두 창을 띄워 동시에 고치면서 화면 위치를 재요)

## 화면 모양 · 글 규칙
- **글자 메뉴**(글자를 고르면 위에 떠요 — 앱은 자리만 잡고 안의 단추는 플러그인 `bold` · `italic` · `strike` · `code` · `h1~3` · `highlight`가 채워요): 굵게 · 기울임 · 취소선 · 코드 · 제목 1~3 + 형광펜 기본 6색 + **내가 최근 고른 색 2개** + **색 더 보기**(네 점 단추). 막대는 늘 한 줄로 작게, 더 보기를 누르면 아래에 작은 칸이 열려요: **색 더** 18개(한 단계 진한 파스텔 9 · 또렷한 색 9) · **내가 고른 색 전부** · 색 고르기(무지개 점). 색 고르기로 칠한 색은 **모두 기록**돼요(최근에 쓴 것이 앞, 같은 색은 하나 — DB `plugin_data` 'highlight' `colors`, 다른 창 · 기기도 같아요. 예전 'core' `hl_colors`도 읽어요). 기록의 색을 ⌥/Alt+클릭(또는 오른쪽 클릭)하면 묻고 기록에서 빼요(이미 칠한 글자는 그대로). 다른 글자를 고르면 더 보기 칸은 다시 접혀요.
- **진행 표시** (`progress.js`): 서버와 주고받는 일이 0.3초 넘게 걸리면 화면 맨 위에 가는 막대가 움직여요(검색 · 플러그인 · 저장 · 내보내기 … 모두 저절로). 얼마나 됐는지 아는 일은 채워지는 막대와 %로: 파일 올리기(알림에 '올리는 중… 2/5 · 45%'), PDF 받기(쪽 번호 자리에 '불러오는 중… 45%'). 큰 이미지를 여는 동안, 아직 그리는 중인 PDF 쪽(반짝이는 빈 쪽), 앱이 처음 뜰 때('불러오는 중…')도 보여줘요. 코드에서는 `progress()`(진행률) · `busy()`(모르는 일).
- **툴팁**: 아이콘 · 단추에 마우스를 올리면 하는 일이 작은 말풍선으로 떠요 (`tooltip.js` — `title`이 있는 요소, 글자 없는 단추는 `aria-label`. 앱 · 플러그인 모두 따로 붙일 것 없이). 터치 화면에서는 뜨지 않아요.
- **모양**: 색 · 둥글기 · 그림자 · 글자 크기는 `style.css` 맨 위 토큰(`--fs-md` · `--fs-sm` · `--fs-title` · `--r-*` · `--danger` · `--ok` · `--star` …)만 써요. 앱 창(`.pdf-dlg`)과 플러그인 창(`.wfx-dialog`)은 같은 여백 · 제목 · 입력칸 · 단추예요.
- **말투**: 해요체 ("~했어요", "~하세요"), 문장 끝 마침표 없이. 실패는 "~하지 못했어요: 이유".
- **낱말**: 항목(노드 ✗) · 내려받기(다운로드 ✗) · 올리기(업로드 ✗) · 누르기(클릭 ✗, 단 "⌘/Ctrl+클릭" 같은 조합은 그대로) · 지금 화면(현재 화면 ✗).
  지우기 = 항목 · 북마크 · 그린 것 · 쪽을 없애기, **삭제** = 첨부 파일을 컴퓨터에서 완전히 없애기만. 선택 = 항목 · 파일을 고르는 '선택', 고르기 = 보기 중 하나를 고르기.
- **지우기 · 삭제는 늘 한 번 더 물어요**: 항목(⌘⇧Backspace · 선택 후 Backspace · 선택 막대) · `delete` · PDF/이미지 북마크 · 구간 반복 기록 · PDF 쪽 · 펜/형광펜 자국 · 메모 · 글자 · 첨부 파일 삭제 · 안 쓰는 파일 정리. 같은 확인 창(취소 · 빨간 '지우기')을 써요 — 앱은 `confirmDelete(무엇, 덧붙임)`, 플러그인은 `ui.confirmDelete(제목, html)`. 빈 항목에서 Backspace(줄 지우기 · 합치기)와 자르기(⌘X), 지우개 도구는 편집이라 묻지 않아요 (⌘Z로 되돌려요).
- **명령 설명**: "이름 (덧붙임)" — 하는 일을 먼저, 자세한 것은 괄호 안에. 범위는 " — 선택한 항목, 없으면 지금 화면"처럼 괄호 안 끝에. 나열은 " · "(양옆 띄어쓰기).

## 성능 메모: 큰 창에는 '배경 흐림'을 쓰지 않아요
검색 창처럼 목록이 들어 있는 큰 창에 `backdrop-filter`(뒤 화면 흐림)를 쓰면, 항목을 옮길 때마다 브라우저가 뒤 화면을 다시 흐려서 프레임이 16ms → 26ms(p95 50ms)로 느려졌어요(JS 처리는 키당 0.5ms 미만). 그래서 큰 창(검색 창·플러그인 창·PDF 창·모바일 막대)은 불투명 배경(`--panel`)을 쓰고, 작은 알림(토스트·선택 막대)만 흐림을 써요.

## 달력 (`calendar`, ⌃S)
큰 월간 달력이에요. 날짜(YYYY-MM-DD)가 적힌 항목이 그 날짜 칸에 나오고, 누르면 그 항목 안으로 줌인해요.
서버 검색으로 그 달만 가져와서 항목이 많아도 빨라요. PageUp/PageDown 으로 달 이동, "오늘", 줌인한 상태에선 "전체 ↔ 이 항목 안만" 전환, Esc 로 닫기.

## 기기 간 맞추기
백업 파일 가져오기는 **아래에 추가**와 **대체하기**만 해요. 두 기기에서 각자 고친 것을 합치는 일은 `dropbox` 플러그인이 해요 (`api.backup.merge` — 저장소 판을 공통 기준으로 3-way).

- 상대만 고친 글 → 반영. 양쪽이 다르게 고친 글 → Dropbox 글은 그대로, 바로 아래에 `⚠ 충돌 · 이 기기에서 고친 글: …` 항목.
- 상대가 지운 항목 → 여기서 안 고쳤고 남길 하위 항목이 없을 때만 지워요.
- 여기서 지운 항목 아래에 상대가 새로 만든 항목 → 홈 맨 아래 `⚠ 합치기 …` 항목 안으로.
